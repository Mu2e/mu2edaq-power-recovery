How to read this report

FAIL versus UNREACHABLE

FAIL means the check ran and the answer was wrong. UNREACHABLE means the node could not be contacted, so nothing is known about it. They need different responses, so they are never merged.

Dry run

In a dry run, power states are read but no chassis is switched on. The power-on page still shows what would have been done, node by node.
