Command-line entry points

mu2e-power-recovery   drive one or more phases (--phase assess|poweron|network|report|all)
mu2e-power-state      phase 1 only: read-only survey
mu2e-power-on         phase 2 only: the power-on sequence (needs --execute to act)
mu2e-power-netcheck   phase 3 only: the connectivity mesh
mu2e-power-report     phase 4 only: regenerate and optionally post the report

mu2e-node-inventory   print the node inventory the tools will use
mu2e-ipmi-tool        issue one IPMI command through a gateway
mu2e-ssh-probe        show, or run, the exact ssh command used for a node
mu2e-vault-ipmi       verify the Vault path holding the BMC credentials

Every one has a man page; see man mu2e-power-recovery.
